# Common high-density background comparison

This directory contains verification and bootstrap scripts for the saved common
high-density background results. The comparison uses the same genotype-derived fivefold
partitions for the genome-wide and QTL-informed representations. The bootstrap resamples
materials from fixed out-of-fold predictions and does not retrain models.

The scripts read paths supplied by command-line arguments or documented release-relative
locations. No server path, credential or account token is required.
