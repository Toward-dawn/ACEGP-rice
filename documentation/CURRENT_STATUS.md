# Release and verification status

The earlier validation records describe the versions and scopes tested at the time; they are not a new training run of this release package. The recorded reruns covered repeated cross-validation, model controls, ablation, quality subsets, genetic-group analysis, original fixed-split random panels and statistics. The anther R workflow was rerun with a recorded CAMERA cross-platform numerical difference. Figure 3–5 scripts were run with their companion source data in the verification environment.

The additional sparse-background random-region comparison (100 random panels per population, 20 repeated fivefold CV splits) is provided as panel definitions and saved results; the current entry points do not directly rerun its full training workflow. The common high-density background scripts audit saved predictions and perform material-level bootstrap; they do not refit the comparison. Figure scripts generate the code-rendered versions; the manuscript figures received subsequent Illustrator adjustments. The exploratory Q-ACEGP runner was smoke-tested on registered primary r01_f1 against the supplied Section C predictions (maximum absolute difference <= 1.4e-14), but the full 200-fold refit remains a separate computational task.

The code-only manifest check verifies file integrity, not model execution. The matching companion dataset is archived on Zenodo (`https://doi.org/10.5281/zenodo.23900534`); see [provenance and licensing](PROVENANCE_AND_RIGHTS.md) for source citations and third-party licence boundaries.
