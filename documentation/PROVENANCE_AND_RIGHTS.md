# Provenance and rights to confirm

This inventory distinguishes file provenance from redistribution permission. A file's presence or a historical acceptance receipt does not establish that a new licence can be applied to it. The author has selected MIT for original software and CC BY 4.0 for original data/results. These choices do not replace third-party terms or establish unverified redistribution rights.

| Material | Existing provenance evidence | Remaining author confirmation |
| --- | --- | --- |
| Primary prediction inputs and full PLINK source | Frozen sample/marker files, registrations and original source filenames under `prediction_inputs` and `random_controls/primary` | Complete source dataset/publication citation, accession/version and redistribution terms |
| Validation genotype/phenotype inputs | Run/accession mapping in `validation_phenotype_source.csv`, marker lists and frozen registrations | Complete source dataset/publication citation, accession/version and redistribution terms |
| Anther counts and sample metadata | BioProject PRJNA1215770; ENA run metadata and 12-sample map under `anther/sources` and `anther/inputs` | Final dataset citation and terms for derived counts/sample metadata |
| Genome annotation and functional mappings | Existing IRGSP-1.0 annotation filenames and versions; GFF and functional-membership inputs | Exact provider/source citation and applicable redistribution/attribution terms |
| QTL regions | Eight source links in `region_name_mapping.csv`; coordinates and unchanged region IDs | Confirm final bibliography labels; retain distinctions between mapping sources and naming sources |
| Study-created predictions, statistics, fixed panels and derived tables | Frozen result files and registrations | CC BY 4.0 selected for original contributions; confirm creators/rights-holder attribution |

Raw sequencing reads are referenced through original repositories rather than rehosted. Third-party terms continue to apply to reused material. If a resource cannot be redistributed, its access route and the exact required version must be documented before a public release; no files have been removed on that assumption here.


## Scope of the selected data licence

| Material group | Applicable licence treatment |
| --- | --- |
| Study-generated predictions, statistics, registrations and fixed-panel definitions | CC BY 4.0 for the authors' original contributions |
| Reused genotype/phenotype and sequencing inputs, including their derived representations | Original source terms remain applicable; no new licence is asserted for third-party rights |
| Reference-genome and functional annotations or copied literature material | Original provider/author terms retained |
| Tables combining original analyses with externally sourced columns | CC BY 4.0 applies to original contributions only; underlying third-party terms are retained |

This scope is not a declaration that every archive file is wholly owned by the study authors. Detailed provider terms that remain unconfirmed must be completed before public distribution. No original notices have been removed.
