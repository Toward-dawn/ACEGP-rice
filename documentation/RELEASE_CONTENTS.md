# Release contents

The code package contains the frozen ACEGP prediction code, original fixed-split
random-panel workflows, common high-density background result-verification/bootstrap helpers, anther-analysis scripts
and environment records, including Figure 3–5 rendering scripts. It does not contain private credentials, server
login information or the Zenodo data payload.

The matching data package contains analysis-ready inputs, saved results, panel definitions,
anther inputs and Figure 3–5 source data. See the repository README for data placement and
[current status](CURRENT_STATUS.md) for verification and publication limits.
