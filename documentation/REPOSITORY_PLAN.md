Once published, add the real record identifier here and in the README; cite the software version in the data record.

Code and data remain separate. Private repository updates do not change visibility or publish a Zenodo record. The licence scopes are MIT for original software and CC BY 4.0 for original data/results; third-party terms remain applicable.
